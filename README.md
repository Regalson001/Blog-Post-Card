# 📰 Blog Post Card

A clean, modern, and responsive **Blog Post Card component** built using semantic HTML5 and CSS3. This project demonstrates essential front-end development concepts, including CSS backgrounds, custom borders, the box model, typography, spacing, and interactive hover effects.

Designed to showcase fundamental web design skills, this component provides a polished way to present blog articles, news updates, and content previews.

## ✨ Features

- **Semantic HTML5** — Uses meaningful HTML elements to structure headings, images, article summaries, and links.
- **Modern Card Design** — Features a clean background, rounded corners, and balanced spacing.
- **Responsive Image Styling** — Displays a cover image within the card layout.
- **Custom Borders** — Adds distinctive border accents to enhance the visual appearance.
- **Typography and Readability** — Establishes a clear visual hierarchy between the title, description, and call-to-action.
- **CSS Box Model** — Applies margins and padding for consistent spacing and alignment.
- **Interactive Read More Link** — Uses a custom `.read-more` class for a visually distinct call-to-action.
- **Smooth Hover Transitions** — Adds visual feedback when users interact with the link.
- **Maintainable Stylesheets** — Keeps presentation and layout rules organized in a separate CSS file.
- **Accessibility-Focused Design** — Encourages descriptive image alternatives, meaningful link text, and visible keyboard focus indicators.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- A modern web browser.
- [Visual Studio Code](https://code.visualstudio.com/).
- [Git](https://git-scm.com/).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Regalson001/Blog-Post-Card.git
```

**2. Navigate to the project directory**

```bash
cd Blog-Post-Card
```

**3. Open the project in Visual Studio Code**

```bash
code .
```

Alternatively, open the project folder manually in your preferred code editor.

**4. Run the application**

Open `index.html` in your web browser. You can also use the Live Server extension in Visual Studio Code for convenient local development.

No additional dependencies or build tools are required for a standard HTML and CSS project.

## 🎨 Design Principles

This project focuses on the following core design principles:

- **Visual hierarchy:** Makes the article title and call-to-action easy to identify.
- **Readability:** Uses clear typography, appropriate spacing, and sufficient text contrast.
- **Consistency:** Maintains a cohesive approach to colors, borders, and corner radii.
- **Simplicity:** Presents content without unnecessary visual clutter.
- **Responsive design:** Encourages layouts that adapt to different screen sizes.
- **Interactive feedback:** Uses hover states and transitions to improve the user experience.

## ♿ Accessibility

Accessibility is an important consideration in modern web development. Recommended practices for this component include:

- Providing descriptive `alt` attributes for meaningful images.
- Maintaining a logical heading hierarchy.
- Using descriptive link text.
- Ensuring sufficient contrast between text and background colors.
- Providing visible keyboard focus indicators.
- Testing the layout at different viewport sizes and browser zoom levels.

These practices support accessible design. Full WCAG conformance requires testing the completed implementation against the applicable success criteria.
